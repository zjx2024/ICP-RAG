## 连续真实评测

```bash
.venv/bin/python -m scripts.run_icp_eval_campaign \
  --output-dir .artifacts/evals/新的运行标识 \
  --concurrency 1 --repeats 1
```

该命令按三份文件顺序运行全部 100 例，失败答案不跳过后面的样例；配置错误、归档失败、源码/gold/资料指纹变化会停止并记录未完成。输出目录必须是新的。`--repeats 3` 会分别报告三次结果，不把 300 次执行冒充 300 个独立用例。普通 CI 不启动这项联网任务。
